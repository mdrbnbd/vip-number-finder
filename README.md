# ভিআইপি নাম্বার ফাইন্ডার (VIP Number Finder)

রবি (০১৮) ও এয়ারটেল (০১৬) এর **খালি থাকা** ভিআইপি নাম্বার এক ট্যাপে খোঁজার স্ট্যাটিক ওয়েব অ্যাপ। GitHub Pages-এ সরাসরি চলে, কোনো build step নেই।

## ফিচার
- ১৪টি এক-ট্যাপ ভিআইপি প্রিসেট: সেরা মিক্স, ৭৭৭৭, ৫+ একই, ০০০০/৫০০০, ১২৩৪, ৯৮৭৬, আয়না/প্যালিনড্রোম, ABAB (১৮১৮), AABB, ডাবল ব্লক, …৭৮৬, অপারেটর কোড মিল, জন্মতারিখ, কাস্টম
- কাস্টম প্যাটার্ন বিল্ডার: `*` = যেকোনো, `০-৯` = নির্দিষ্ট, `A-Z` = ভেরিয়েবল (যেমন `01*-***7777`, `ABCDDCBA`, `**ABABAB`)
- "অবশ্যই থাকবে" আর "এই সংখ্যা থাকবে না" (যেমন ৪/৯ বাদ) ফিল্টার
- স্মার্ট মাল্টি-সিরিজ সার্চ: অপারেটর যে সাব-সিরিজে নাম্বার ছাড়ছে (০১৮২৫, ০১৬১২…) সেগুলো নিজে শিখে একসাথে খোঁজে, প্রতি সিরিজের প্রোগ্রেস দেখায়
- ভিআইপি স্কোর ০–১০০ আর 💎 ডায়মন্ড / 🥇 গোল্ড / 🥈 সিলভার টিয়ার, "কেন?" চাপলে স্কোরের কারণ দেখায়
- টিয়ার/অপারেটর ফিল্টার, সাজানো, নাম্বারে সার্চ, পছন্দ (localStorage), কপি, শেয়ার, CSV, "আবার যাচাই"
- **কিনুন** চাপলে নাম্বার কপি হয় আর অফিসিয়াল পেজ খোলে
- PWA: ইনস্টল করা যায় (manifest + service worker), ডার্ক/লাইট মোড, মোবাইল-ফার্স্ট

## কীভাবে কাজ করে
রবির পাবলিক availability API (`POST https://da-api.robi.com.bd/da-nll/free-msisdn/get-msisdn-list`, `{msisdn, brand, simCategory:"PREPAID"}`) পুরো ১৩ অংকের নাম্বার (যেমন `8801825777777`) নেয় এবং `available` (নাম্বারটি খালি কি না) আর `freeMsisdnList` (৪টি খালি সাজেশন) ফেরত দেয়। API `Access-Control-Allow-Origin: *` পাঠায়, তাই github.io থেকে ব্রাউজারেই সরাসরি কল করা যায়।
একসাথে সর্বোচ্চ ৩টি অনুরোধ যায়, প্রতিটির পরে বিরতি থাকে, আর 429/5xx হলে exponential backoff হয়।

## লোকাল টেস্ট
```
python3 -m http.server 8099   # তারপর http://localhost:8099
node test.js                  # scoring/pattern টেস্ট
```

## GitHub Pages
রিপো পুশ করে Settings → Pages → Branch `main` / root চালু করুন।

> নাম্বারগুলো অপারেটরের পাবলিক availability চেক থেকে আসে; কেনাকাটা শুধু অফিসিয়াল সাইটে হয়। রবি/এয়ারটেলের সাথে কোনো সম্পর্ক নেই।
